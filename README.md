# Quant Trader MVP - 量化交易系統

這是一個基於 Python 的模組化量化交易系統 MVP，專為台股日線波段交易設計。

## 系統特點
- **模組化架構**：分離資料、策略、回測、風控、下單與監控。
- **避免 Look-ahead Bias**：策略訊號嚴格位移 (Shift 1)，訊號由昨日決定，今日開盤執行。
- **健全風控**：支援單一持倉上限、最大回撤控制、單日虧損限制。
- **擬真回測**：考慮手續費、證交稅與滑價。

## 安裝步驟
1. 確保 Python 版本 >= 3.10
2. 安裝套件：
   ```bash
   pip install -r requirements.txt
   ```

## 快速開始
1. 執行回測：
   ```bash
   python main_backtest.py
   ```
2. 查看結果：
   - 控制台會顯示基本績效。
   - `reports/` 資料夾下會產生 `equity_curve.png` 與 `summary.json`。
   - `logs/` 資料夾下可查看詳細交易過程。
